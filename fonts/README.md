# Runtime typefaces

- **Bungee Regular** — David Jonathan Ross; used for cinematic titles, major HUD calls, and arcade display text. Licensed under the SIL Open Font License 1.1; see `Bungee-OFL.txt`.
- **Chakra Petch Medium/Bold** — Cadson Demak; used for dialogue, menus, and compact HUD text. Licensed under the SIL Open Font License 1.1; see `ChakraPetch-OFL.txt`.

Both families are self-hosted so the installed/offline game keeps its intended typography without contacting a font service.
